# Mathibot - Smart Math Assistant

![Mathibot Logo](design/assets/logo.png)

**Mathibot** is a lightweight, intuitive mathematical assistant designed to help students and enthusiasts solve geometry problems and practice bridge arithmetic. Born from a secondary school project, it has evolved into a sleek "beta" tool with a focus on ease of use and visual clarity.

## Features

- **Geometry Calculator**: Quickly find Perimeter and Area for:
  - Squares
  - Rectangles
  - Triangles
  - Circles
- **Random Challenges**: Test your mental math skills with dynamically generated exercises.
- **Educational Insights**: Each shape comes with basic definitions and formulas to help you learn why the math works.
- **Modern Aesthetic**: Dark mode by default with smooth transitions and a clean UI.

## Project Structure

- `app/`: The core application code (HTML, CSS, JavaScript).
- `design/`: UI/UX assets, images, and original layout designs (PSD/PNG).

## Installation & Usage

Since Mathibot is built with standard web technologies, there's no installation required:

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/mathibot.git
   ```
2. Open `app/index.html` in any modern web browser.
3. In PC, select inspector (F12) and select responsive design mode for mobile phones
4. Start calculating!
